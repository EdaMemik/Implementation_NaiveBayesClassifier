# Implementation_NaiveBayesClassifier
This python prgram implements a Naive Bayes Classifier to see the positive or negative bias in a given sentence. This is done by analyzing a large set of positive and negative movie reviews.

In order to run this program you must have all the datasets and python in the same file as main.py and NaiveBayesClassifier.py. In order to then run the program you must be in terminal at the directory of the folder all the files are in. they you must run python3 main.py. You will be prompted on how to interact with the program. 

The more definitive your sentence is the more accurate the program will be. Sometimes a positive or negative sentence may be mischaracterized because the sentence wasnt as clear as it could be.
